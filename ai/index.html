How an LLM works

It predicts the next word, again and again

Your prompt

"Python is a ..."

Tokens

text split into small pieces

Model

billions of learned numbers

Next token

"programming" → "language" ...

A token is a piece of a word (about ¾ of a word in English). The model reads and writes tokens, one at a time.

Know the limits

What LLMs are bad at

Hallucination

It can say wrong things very confidently, even fake facts, fake links and fake functions.

Old knowledge

It only knows what was in its training data, unless it can search the web.

No real memory

Each chat starts fresh unless the tool saves memory for you.

Maths and counting

It predicts words, so long calculations can go wrong. Ask it to use code.

Part 2

Prompt Engineering

How to ask so you get what you need

The golden rule

Vague prompt in, vague answer out.

Prompt engineering = writing clear instructions so the AI gives you exactly what you need.

The 6-part prompt

A good prompt has these parts

1 · Role

Who should the AI act as? "You are a senior Python developer."

2 · Task

What exactly do you want? "Explain this error."

3 · Context

Background it needs: your level, your code, your goal.

4 · Format

How the answer should look: steps, table, code only, 5 bullets.

5 · Examples

Show one sample of what good output looks like.

6 · Constraints

Limits: "under 100 words", "no libraries", "beginner words".

Bad vs good

Same question, two prompts

❌ Bad

fix my code

✅ Good

You are a Python teacher.

My Flask withdraw route lets the balance

go below zero. Here is the code:

paste code

1. Find the bug.

2. Show the fixed code.

3. Explain the fix in 3 simple lines.

The good prompt has role, context, task and format. It takes 30 seconds more and saves 10 minutes.

Few-shot example

Teach by showing

Convert the task into a git commit message.

 

Task: added login page with email and password

Commit: Add login page with email/password form

 

Task: fixed bug where balance went negative

Commit: Fix withdraw allowing negative balance

 

Task: added 4 percent interest button to bank page

Commit:

Two examples teach the pattern. The AI fills in the last line in the same style.

Prompts for students

Use AI to learn, not to skip learning

Learn a concept

Explain SQL JOIN like I am a beginner, with a small student-marks example. Then give me 3 practice questions.

Understand an error

I got this error in Spring Boot: «error». Explain what it means and the 3 most likely causes.

Interview practice

Act as an interviewer for a fresher Python role. Ask me one question at a time and rate my answer.

Resume help

Here is my project: «details». Write 2 resume bullet points with action verbs. Don't add anything I didn't do.

Common mistakes

Prompt mistakes to avoid

You seeFix
"write code for bank app"Say the language, features, and what you already have
Pasting 500 lines with no questionPaste only the part that matters + say what is wrong
Accepting the first answerAsk follow-ups: simpler, shorter, add tests, explain line 5
Trusting it blindlyRun the code. Check facts. Ask "are you sure? show a source"
Pasting passwords or API keysNever share .env, keys, passwords or personal data

Agentic AI

From AI that talks to AI that does work

The difference

Chatbot vs AI agent

ChatbotAI agent
What it doesAnswers your questionCompletes a goal for you
StepsOne replyMany steps, one after another
ToolsUsually noneUses tools: web search, code, files, APIs
DecisionsYou decide what's nextIt decides the next step itself
Example"How do I book a train ticket?"Searches trains, compares, fills the form, asks you before paying

How an agent works

The agent loop

Goal

what the user wants

Think / Plan

decide the next step

Act

use a tool

Observe

check the result

It repeats Think → Act → Observe until the goal is done, or it stops to ask you.

Inside an agent

4 building blocks of every AI agent

Brain · LLM

Understands the goal and decides what to do next.

Tools

Functions it can call: search, run code, read files, call APIs, send email.

Memory

Remembers earlier steps and useful facts.

Guardrails

Rules and limits: what it may do alone, and when it must ask a human.

Connect it to your project

Your Bank API can be an agent's tool

User:  "Withdraw 500 and email me the new balance"

 

Agent thinks: I need the withdraw tool.

Agent acts:   POST /api/withdraw  {"amount": 500}

Observes:     {"balance": 9500}

 

Agent thinks: now send the email.

Agent acts:   send_email(to, "New balance: Rs 9500")

Observes:     email sent

 

Agent:  "Done. Rs 500 withdrawn. Balance Rs 9500. Email sent."

Agents don't replace APIs. Agents use APIs. The backend you built this week is exactly what agents need.

Use AI the right way

5 rules for using AI

Understand it

Never submit code you can't explain. Interviewers will ask you to explain it.

Verify it

Run the code, test it, check facts from a real source.

Protect data

No passwords, API keys, .env files or personal data in prompts.

Be honest

Follow your college rules. Don't present AI work as yours in exams.

Stay in charge

AI suggests; you decide. Especially before sending, paying or deleting.

Interview corner · answers

AI questions asked in fresher interviews

1. What is the difference between AI, ML and Deep Learning?

AI is any machine doing smart tasks. ML is AI that learns from data. Deep learning is ML using many-layer neural networks.

2. What is an LLM?

A Large Language Model: a deep learning model trained on huge text data that predicts the next token to generate text, like ChatGPT or Gemini.

3. What is hallucination?

When an AI gives wrong or made-up information confidently. That's why we always verify its output.

4. What is prompt engineering?

Writing clear instructions (role, task, context, format) so the AI gives the exact output we need.

5. What is an AI agent?

An AI system that works toward a goal in steps, using tools like APIs or code, and checking results until the task is done.
