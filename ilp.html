How a workshop runs

Three days, one clear outcome

Every student leaves with working projects on their own GitHub and a clear next step.

Before: setup and a quick skill check

A laptop setup guide for the lab, plus a short pre-workshop form so we know each student's level.

Day 1: foundations

Command line, Git and GitHub in VS Code, programming basics, HTML and CSS, and the first project.

Day 2: backend and data

SQL and databases, APIs and CRUD, login and sign-up, and a bank account project in guided steps.

Day 3: finish, push, prepare

Students finish and push their projects to GitHub, then aptitude, communication and mock interviews, a final quiz and feedback.

After: report and support

A short report for the college (attendance, progress, feedback) and doubt support for students.
